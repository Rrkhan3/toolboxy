JSON Validator

Use this free online json validator to check if JSON is valid. It works right in your browser, with no sign-up.

Everything runs in your browser. Your input is not sent to a server.

How to use the JSON Validator

  1. Paste or type your code or text into the input editor.
  2. Press the action button (Format, Validate, Encode, Decode or Generate).
  3. Copy or download the output. HTML, CSS and JavaScript tools also offer a sandboxed Preview tab.

How it works

It uses the browser JSON.parse function. Valid JSON is confirmed with its root type, invalid JSON shows the error message.

Example

{"name":"A"} is valid, while {name:'A'} is invalid because keys need double quotes.

JSON Validator FAQ

What are common JSON errors?

Trailing commas, single quotes, unquoted keys and comments.

Does it check a JSON schema?

No. It checks syntax only.

Is the JSON Validator free to use?

Yes. It is free, needs no account and runs in your browser.
