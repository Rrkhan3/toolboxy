Image to Base64 Converter

Use this free online image to base64 converter to convert an image to a Base64 data URL. It works right in your browser, with no sign-up.

Your image is processed locally in your browser and is never uploaded.

How to use the Image to Base64 Converter

  1. Choose an image or drag and drop it onto the upload box.
  2. Set the options you need.
  3. Press the action button, check the preview and download the new image.

How it works

The file is read with the browser FileReader API and returned as a data URL that starts with data:image/...;base64.

Example

A small PNG gives text that starts with data:image/png;base64,.
